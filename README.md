# 个人主页

个人主页：Node.js 静态站点服务。零依赖，只用 Node.js 内置模块提供 `public/` 目录下的静态页面。

## 本地运行

```bash
npm start
```

服务默认监听 `8080` 端口。

## 环境变量

- `PORT`：监听端口，默认 `8080`。
- `UUID`：服务启动时读取的标识，必填，未设置时启动会报错退出。请在部署平台的环境变量里设置，不要写进仓库。
- `WS_PATH`：可选，默认 `/assets/v2/config`。

启动脚本会从上游下载运行所需的二进制文件并生成本地配置文件（`config.json` 与 `bin/` 已在 `.gitignore` 中，不会提交到仓库）。
